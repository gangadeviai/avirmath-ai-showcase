# Datasets

All three are from the UCI Machine Learning Repository and are redistributed here unchanged
under their CC BY 4.0 licence, so the tests and the on-screen experiments run offline.

| Folder | Dataset | Citation |
|---|---|---|
| `data/german/` | Statlog (German Credit Data) | Hofmann, H. (1994). UCI Machine Learning Repository. https://doi.org/10.24432/C5NC77 |
| `data/bike/` | Bike Sharing (hourly) | Fanaee-T, H. and Gama, J. (2013). Event labeling combining ensemble detectors and background knowledge. *Progress in Artificial Intelligence*. https://doi.org/10.24432/C5W894 |
| `data/dermatology/` | Dermatology | Güvenir, H. A., Demiröz, G. and İlter, N. (1998). Learning differential diagnosis of erythemato-squamous diseases using voting feature intervals. *Artificial Intelligence in Medicine*, 13(3), 147–165. https://doi.org/10.24432/C5FK5P |
