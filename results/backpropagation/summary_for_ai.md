# What Is Backpropagation? The Chain Rule That Trains Every Neural Network

**What is backpropagation?** Backpropagation is the algorithm that computes how much a neural network's error changes with respect to every weight, in a single backward pass, by applying the chain rule from the output back to the input. Published for neural networks by Rumelhart, Hinton and Williams in 1986, it supplies the gradient that gradient descent uses to train every modern network.

## Key facts
- **What is backpropagation in simple terms?** A way to find out, for every weight in a network, how much the error would change if that weight moved — all in one sweep from the output back to the input.
- **Is backpropagation the same as gradient descent?** No. Backpropagation computes the gradient; gradient descent uses it to update the weights. One supplies the direction, the other takes the step.
- **Who invented backpropagation, and when?** Reverse-mode differentiation was described by Seppo Linnainmaa in 1970. Paul Werbos applied it to neural networks in 1974, and Rumelhart, Hinton and Williams showed its power in Nature in 1986.
- **Why is it called back-propagation?** Because the error signal is propagated backwards: each layer's derivative is computed from the layer after it, reusing work instead of recomputing it.
- **Why does backpropagation need the chain rule?** A network is a composition of functions. The derivative of a composition is the product of the derivatives of its parts, and backpropagation multiplies those parts in the cheapest order.
- **What is the vanishing gradient problem?** Each sigmoid layer multiplies the backward signal by at most a quarter, so after many layers the gradient reaching the early weights is tiny. It is why ReLU, residual connections and normalisation exist.
