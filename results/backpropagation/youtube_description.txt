Backpropagation is the algorithm that computes how much a neural network's error changes with respect to every weight, in a single backward pass, by applying the chain rule from the output back to the input. Published for neural networks by Rumelhart, Hinton and Williams in 1986, it supplies the gradient that gradient descent uses to train every modern network.
